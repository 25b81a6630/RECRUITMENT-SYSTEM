# RECRUITMENT-SYSTEM
The Recruitment System is a web-based platform that connects candidates, recruiters, and administrators. It enables job posting, job searching, online applications, resume management, application tracking, and candidate shortlisting. The system focuses on security, performance, reliability, and user-friendly recruitment management.
